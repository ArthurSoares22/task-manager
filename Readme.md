# Task Manager API

## O que é
API REST de gerenciamento de tarefas com autenticação JWT.

## Tecnologias
- Node.js
- Express
- SQLite
- bcrypt
- JWT

## Como rodar
1. npm install
2. Copiar .env.example para .env e preencher
3. npm run dev

## Rotas disponíveis
POST /auth/register — cadastro de usuário
POST /auth/login — login (em desenvolvimento)
